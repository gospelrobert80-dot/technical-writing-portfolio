# User Profile API Reference

## User Profile Data Fields

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `username` | String (Text) | The unique username used to identify the user's profile. |
| `age` | Number | The user's age in years. |
| `location` | String (Text) | The country or place where the user is located. |
| `account_status` | String (Text) | Shows whether the user's account is active or inactive. |
